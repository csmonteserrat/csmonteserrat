# Histórico de versões

## Versão 1.1

- O CELK passou a ter prioridade obrigatória nos cálculos quando houver dados para a competência.
- O Metabase passou a funcionar como referência consolidada e como alternativa somente para meses sem CELK.
- Divergências entre as duas fontes agora geram observação visível com numerador, denominador e resultado de cada origem.
- A identificação da versão foi adicionada às configurações da ferramenta.

## Versão 1.0

- Primeira versão publicável para GitHub Pages e Render.
